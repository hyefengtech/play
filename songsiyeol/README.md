# 송시열 빙의: 남인 공략 시뮬레이터 · VN v3

- `index.html`을 열어 플레이하세요. 별도 서버나 라이브러리가 필요 없습니다.
- `scenario.json`은 시나리오 원본, `data.js`는 브라우저용 데이터입니다.
- 7개 배경 CG, 4개 인물 패널 CG, 7장 대사/선택/반응, 5장·6장 관계 이벤트, 4종 엔딩 포함.
- 캐릭터 이미지는 기존 합본에서 분리한 **배경이 남아 있는 패널 CG**입니다. 투명 PNG가 아닙니다.
- 표정은 시나리오 데이터에 기록되어 있지만 현재 원화가 표정별 독립 CG가 아니므로 화면에는 단일 스탠딩 이미지가 표시됩니다.
- 엔딩 판정: 최고점-최저점이 1 이하이면 BAD, 그 외 최고점 캐릭터 엔딩 (동점은 HM > YH > HJ).
- 실제 역사와 다른 대체역사 창작물입니다.

## v3.1 송시열 대사 UI
송시열이 말할 때 대사창 왼쪽에 송시열 얼굴 이미지가 나타납니다. 다른 인물은 기존 스탠딩 연출을 유지하고 송시열 발화 시 허목이 강조되는 오류를 수정했습니다.

## v3.2 최고점 2인 동점 결단 이벤트
- 7장 종료 후 최고점이 **두 명 동점**이면 궁궐 앞마당에서 전용 대화와 선택지 2개가 나타납니다. 직접 고른 캐릭터 엔딩으로 진행합니다.
- **세 명 모두 동점**이면 선택 이벤트 없이 기존 BAD 엔딩입니다.
- **단독 최고점**이면 기존 판정 유지(최고점-최저점이 1 이하이면 BAD).
- 동점 결단 이벤트 중에도 저장/이어하기가 가능합니다. 기존 v3.1 세이브 키를 유지합니다.

## v3.3 송시열 9종 표정 자동 전환
- 사용자가 제공한 3×3 표정집에서 자막 부분을 제외하고 9개 얼굴 이미지를 개별 WebP로 분리했습니다.
- `assets/characters/songsiyeol_expressions/`에 `default`, `smile`, `surprised`, `angry`, `sad`, `joy`, `hopeful`, `shy`, `lovestruck` 파일이 있습니다.
- 송시열 대사는 `expression` 값(기본/미소/당황/분노/슬픔/즐거움/기대/부끄러움/설렘)을 우선 적용하고, 없는 경우 대사 내용으로 표정을 추정합니다.
- 7장 및 프롤로그 주요 송시열 대사에는 명시적 감정 태그를 추가했습니다.
- 최고점 2인 동점 최종 선택, 3인 동점 배드엔딩 및 기존 CG/배경/저장 기능은 유지합니다.
- **주의:** 원본 표정집의 각 패널에 배경이 있으므로 투명 배경이 아닌 얼굴 초상화입니다.


v3.4: 엔딩 CG 변경 — YH 윤휴 포옹, HJ 허적 다정한 장면, HM 허목 공동 집필. BAD는 기존 송시열 이미지 유지. 3종 이미지는 assets/endings/ 폴더에 포함.

## v3.5 엔딩 갤러리
- 오프닝 화면의 「엔딩 갤러리」 버튼으로 진입합니다.
- 윤휴·허적·허목 엔딩을 실제로 달성하면 CG가 해금됩니다.
- 해금 기록은 진행 저장과 별도의 localStorage 키(yesong-vn-gallery-unlocks-v1)에 보존됩니다.
- 미해금 CG는 잠금 처리되며, 해금한 CG는 클릭해서 확대 감상할 수 있습니다.
- 브라우저 저장소를 지우거나 다른 기기에서 열면 해금 기록이 이전되지 않습니다.


## v3.6 갤러리 해금 기록 초기화
엔딩 갤러리 아래의 「해금 기록 초기화」를 누르면 확인 후 해금 기록만 삭제합니다. 저장 키 `yesong-vn-gallery-unlocks-v1`만 제거하며 게임 진행 키 `yesong-vn-scenario-v3`는 보존합니다.
